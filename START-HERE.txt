TRACE — проект для передачи другу

1. Распакуйте ВЕСЬ архив в отдельную папку на Windows 10/11 x64.
2. Установите Python 3.12 или новее с python.org (при разработке использовался Python 3.14).
3. Запустите START.cmd. При первом запуске нужен интернет: устанавливаются Python-зависимости.
4. Откроется http://127.0.0.1:5174/ . Если браузер не открылся — откройте адрес вручную.
5. Для остановки нажмите Ctrl+C в окне сервера. Следующий запуск — снова START.cmd.

Node.js, Docker и отдельная сборка интерфейса для этого запуска не нужны: dist включён.
Порты 5174 и 8878 должны быть свободны. Сервер доступен только на этом компьютере.
Не запускайте START.cmd прямо из ZIP. При ошибке сохраните текст из окна.

Состав: исходники backend/frontend, production-сборка интерфейса, тесты и документация.
Личная база автора, пароли, .env, логи и установленные зависимости НЕ включены.
При запуске создаётся новая изолированная учебная база в trace-core/work/local-demo.
Демонстрационные данные и намеренно уязвимый тестовый исходник предназначены для локальных проверок.

Встроенный Python AST-анализ, импорт отчётов и локальная проверка HTTP-заголовков доступны
без внешних движков. Semgrep, OSV, Trivy, внешние CI/CD и активный DAST не поставляются
настроенными: их подключение описано в trace-core/docs/platform/37-connected-engines.md.
Это локальный прототип; полнота промышленной платформы не заявляется.
Для разработки frontend: trace-frontend/package.json и README backend.

MANIFEST.json содержит SHA256 всех файлов пакета (кроме самого манифеста).
